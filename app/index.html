.pigeon 课程包格式

像投递包裹一样制作、分享课程

.pigeon 本质是 zip 压缩课程包,把课程元信息、知识点正文、题库、术语表和图片资源放在同一个可分享文件里。

mycourse.pigeon
├─ manifest.json
├─ content.json
├─ quiz.json
├─ glossary.json
└─ assets/images/
manifest.json课程 id、标题、版本、章节索引和首页统计。
content.json概述与知识点正文,由 paragraph、image、table 等类型化块组成。
quiz.json小节小测和章节考试题库,支持 single、judge、sort、match。
glossary.json术语表数组,字段为 {t, full, cn, d}。

格式保留 html 内容块和开放题型枚举。未来可以增加 HTML 片段、更多题型或新的资源类型,旧课程仍能被基础渲染器跳过未知类型后继续学习。

用 Claude Code？装上「课程包 Skill」

仓库内置了一个 Claude Code Skill：.claude/skills/pigeon-course-authoring/。在本仓库里用 Claude Code 时，说「帮我把这份教材做成 .pigeon 课程」即可自动套用制作流程、字段规范与打包脚本，并带最小示例课程。

移植到别的机器：把该目录整个放进目标项目的 .claude/skills/ 下即可（打包仍需在本仓库进行）。也可从 GitHub 获取：

github.com/HELUOO404/Pigeon_Library · .claude/skills/pigeon-course-authoring
