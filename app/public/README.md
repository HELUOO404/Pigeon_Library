# app/public/ — 站点静态资源

Vite 原样拷贝到产物根;页面用绝对路径引用(如 `/brand-logo.svg`)。

| 文件 | 说明 |
|---|---|
| `brand-logo.svg` | PigeonLib **站点品牌标**:邮戳圆环 + 折纸信鸽 + 火漆印。用于 favicon、首页/学习页顶栏。 |

注意:**站点 logo 与课程封面是两回事**。课程封面在 `courses/<id>/cover.png`(或 manifest `coverText`),勿把课程图当站点 logo。品牌色见 [设计系统](../../docs/design-system.md)。
