# app/src/styles/ — 样式

| 文件 | 职责 |
|---|---|
| `tokens.css` | **设计令牌单一来源** + 基础重置 + 图标基样式。邮政编辑风色板、语义令牌、字体、布局、亮/暗主题、遗留别名。两页都 `@import` 它。 |
| `home.css` | 首页样式(英雄区 / 课程投递卡 / 格式手风琴 / 页脚)。只写布局组件,不再自带 `:root`。 |
| `learn.css` | 学习页样式(顶栏 / 动画三级目录 / 知识卡 / 原生 tab、列表、图片组、富表格 / 小测 / 考试 / 面板 / 术语 / 沙箱)。含正文与列表缩进、`paramsTable`/`compareBox` 窄容器纵向记录、legacy 兼容滚动壳及隔离沙箱的原生模式栏。 |

规则(见 [设计系统](../../../docs/design-system.md)):
- **颜色只用令牌**,不写死色值;改色板只改 `tokens.css`。
- **禁用元素**:无 UI emoji(用图标)、**无竖向装饰线**(不用 `border-left/right` 做 accent,改横线/序号/背景色差)。
- 字体:标题 `--serif`、正文 `--sans`、数据 `--mono`。
