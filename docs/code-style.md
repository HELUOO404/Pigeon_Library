# 代码风格与中文注释规范

> 目标:代码对人类友好、注释规范不冗杂。返回索引:[`../CLAUDE.md`](../CLAUDE.md)。

## 一、中文注释规范

注释用**中文**,标识符/技术术语保留英文。原则:**解释"为什么"多于"是什么"**,不解释显而易见的语法,不冗余。

1. **文件头**(每个源码文件第一行):
   ```js
   // <文件名> — <一句话职责>
   ```
   例:`// quiz.js — 小节小测:渲染判分、结果恢复;答错时按题库 id 记入错题本。`

2. **区块**:较长文件用分隔注释分组:
   ```js
   /* ============ 考试 ============ */     // CSS
   // ==== 区块名 ====                       // JS
   ```

3. **关键函数 / 非直观逻辑**:函数上方或行内一句中文,讲清意图或"坑":
   ```js
   // 用题库 id 作为错题 key:同一道题在小测与考试共享同一 id,错题本因此不会记两条。
   ```

4. **不写**:逐行翻译式注释、与代码重复的废话、被注释掉的死代码(直接删或说明原因)。

## 二、JSONC(课程 JSON)注释约定

课程的 `manifest/content/quiz/glossary.json` 支持 `//`、`/* */` 注释与尾随逗号(加载时由 `pigeon-loader` 剥离)。约定:

- 每个 JSON **开头放一段"字段图例"块注释**,讲清各字段含义。
- 数组中重复结构(章节、知识点、题目)**只在第一项注释当模板**,其余不重复。
- 正文不逐条重复,只在结构不直观处点一句。
- 细节见 [`pigeon-format.md`](./pigeon-format.md) 与 [`ai-course-authoring-prompt.md`](./ai-course-authoring-prompt.md)。

## 三、CSS 约定

- **颜色只用令牌**(`var(--...)`),不写死十六进制;改色板只改 `tokens.css`。
- 遵守[设计系统](./design-system.md)的"禁用元素":**无 UI emoji、无竖向装饰线**。
- 单文件按区块组织 + 区块注释;选择器命名沿用现有 class(渲染器依赖,勿改名)。

## 四、JS 约定

- ES Module,浏览器原生(无打包期魔法);`core/` 与内容无关,`render/` 负责把数据转 DOM。
- 动态 HTML 用模板串时,**所有外部/课程数据经 `escapeHtml`**;需要嵌图标时用 `icon()` 并对动态文本转义(见 quiz.js 反馈区写法)。
- 改动遵循**外科手术式**:只动与需求相关的行,不顺手重构/格式化无关代码;清理自己改动产生的孤儿(未用 import/变量),不删既有无关死代码(发现则提示)。
- 命名:见名知意;函数动词开头;模块单一职责。
