## 3. 各区块说明(内容 / 交互 / 数据来源)

| 区 | 显示 | 交互 | 数据来源 |
|----|------|------|----------|
| A 顶栏 | 圆形 logo + 「PigeonLib」+ 锚点导航 + 🌙 | 锚点平滑滚动;🌙 复用原 `toggleTheme()`,写 localStorage(与学习页共享主题) | 静态 + 主题偏好 |
| B Hero | 品牌意象、产品名、slogan、简介、双 CTA、统计条 | 「浏览课程」滚到 C 区;「了解格式」滚到 E 区并展开首面板 | 文案静态;统计数 = 内置数 + 本地数 |
| C 内置课程 | 区标题 + 课程卡网格(当前 1 张 IC 封装) | 点卡/按钮 → 学习页(带课程 id) | 平台内置清单,只读不可删 |
| D 我的课程 | 上传 dropzone + 本地课程卡(右上角删除/更多) | 上传成功即时插卡;点卡进学习;删除需二次确认 | 浏览器本地:图片存 IndexedDB,索引存 localStorage |
| E 格式说明 | 5 个手风琴面板:是什么/目录树/字段/AI 指南/可扩展性 | 点击展开收起(复用原折叠动画);AI 指南内含「一键复制提示词」 | 静态文档 || F 页脚 | 版权、版本、文档/GitHub 链接、鸽子图标 | 外链新开页 | 静态 |

### E 区面板 4「🤖 给 AI 的课程制作指南」内容清单

该面板是产品核心卖点(让 AI 把教材转成 `.pigeon`),内含一段可**一键复制的提示词**,覆盖:

1. **整体约定**:目录结构、各 JSON 的 schema、id 命名(`章-节-知识点`)、图片相对路径、`schemaVersion`。
2. **content.json**:教材正文如何切知识点并映射节点类型。
3. **术语表制作指南**:让 AI 从教材自动抽取缩写/专有名词,生成 `{t, full, cn, d}` 四元组;`t` 用正文实际写法(含 `T/C` 这类)以保证悬浮提示命中;释义一句话讲清。
4. **题目解析制作指南(重点)**:针对「只有题目没有解析」的课程,指导 AI 自动生成**优质解析**写入 `exp/explain`——① 为什么对;② 其他选项为什么错;③ 关联知识点;④ 记忆要点;并按题型(single/judge/sort/match)区分侧重;须基于课程正文,不编造。
5. **可扩展性**:未来 HTML 片段、更多题型的约定。

## 5. 上传交互五态

同一组件随状态切换文案、边框色、图标,配色取自原站 token。

| 状态 | 边框/底色 | 文案要点 |
|------|-----------|----------|
| ① 默认 idle | 虚线 `--cbd` / `--cbg` | 「拖拽 .pigeon 到这里 / 选择文件」+ 「≤50MB · 全程本地解析」 |
| ② 拖拽悬停 drag-over | 2px 虚线 `--c1` / `--chv` | 「松手即可导入」+ 高亮放大 |
| ③ 解析中 parsing | 实线 `--c1` | 「解压 → 校验 manifest → 读题库 → 缓存图片」+ 进度条,按钮禁用 |
| ④ 成功 success | `--cs` 绿 / `--cCorrectBg` | 「✓ 导入成功:《课程名》」+ 即时入网格并高亮 |
| ⑤ 失败 error | `--cd` 红 / `--cWrongBg` | 「✕ 无法导入:<具体原因>」+ 引导到格式说明 |

**失败原因文案(逐条具体,便于制作者/AI 排错)**
- 不是 zip / 无法解压 → 「文件已损坏或不是 .pigeon 课程包」
- 缺 `manifest.json` → 「缺少 manifest.json」
- manifest 字段缺失/JSON 语法错 → 「manifest 格式错误:缺少 title / version」
- 缺 `content.json` → 「课程内容缺失」
- 引用图片找不到 → 警告级:可导入,提示「N 张图片缺失」
- 超大小限制 → 「文件超过 50MB 上限」

## 6. 配色 / 间距

颜色全部沿用原站 `:root` / `[data-theme="dark"]`:主色 `--c1` `#1a73e8`(暗 `#8ab4f8`)、背景 `--cbg`、卡面 `--csf`、正文 `--ctx`、次要 `--ctx2`、边框 `--cbd`、高亮 `--chv`、成功 `--cs`、失败 `--cd`、圆角 `--r 8px`(卡片 12px)、阴影 `--sh`。

**新增首页专用变量(并入同一 `:root`)**
- `--brand-grad`:Hero 与无封面占位渐变,亮 `linear-gradient(135deg,#1a73e8,#4a9af5)`,暗 `linear-gradient(135deg,#669df6,#8ab4f8)`。
- `--badge-builtin` = `--c1`;`--badge-local` = `--cs`。

**间距节奏(8px 基准)**:顶栏 56px;内容最大宽 1080px 居中;桌面左右留白 24px(移动 16px);Hero 上 64px/下 48px;区块间 48px;区标题与网格 16px;卡片网格 gap 20px;卡片内距 16px;折叠面板标题内距 16px×20px;按钮内距复用 `10px 28px`。

**原则**:区块用 48px 大间距制造呼吸感,区块内用 16/12/8px 收紧;卡片统一 12px 圆角 + `--sh` + hover 上浮,与学习页 `knowledge-card` 观感一致,保证「同一产品」的视觉连续性。
