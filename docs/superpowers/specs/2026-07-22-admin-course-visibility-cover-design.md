# 管理端课程可见性与封面编辑设计

## 背景

管理面板已经支持编辑课程标题、副标题、分类、发布人、作者和简介，以及删除课程。本次扩展课程展示管理能力：管理员可以独立控制课程是否出现在公开课程列表中，并可覆盖课程卡片封面，同时对照课程来源中的原始展示信息。

本设计采用课程级展示覆盖。审核状态、课程版本和 `.pigeon` 文件保持不变。

## 目标

- 管理员可为上传课程和内置课程设置“显示 / 隐藏”。
- 管理员可在原封面、图片封面和文字封面之间切换。
- 文字封面接受 1–6 个字符。
- 编辑时同时展示课程来源中的原始展示和平台当前展示。
- 恢复原封面时只清除封面覆盖，不影响其他元数据修改。
- 保持本地优先：后端离线时，内置课程继续使用静态默认信息。

## 非目标

- 不修改、重打包或替换 `.pigeon` 文件。
- 不创建课程新版本，不改变文件哈希。
- 不允许管理员通过可见性开关修改 `private / pending / published / rejected` 审核状态。
- 不改变课程所有者在“我的课程”中的管理能力。
- 不把分类、发布人或可见性写入课程包。

## 术语

- **作者**：课程内容的原创者，对应 `manifest.author`。
- **发布人**：把课程上传或发布到平台的账号或组织，是平台展示字段。
- **原始展示**：来自 `.pigeon` 清单或内置课程登记表、未应用平台覆盖的信息。
- **当前展示**：应用平台元数据、可见性和封面覆盖后的实际展示效果。

## 数据模型

### 上传课程

在 `courses` 增加以下课程级字段：

| 字段 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `visible` | INTEGER | `1` | `1` 显示，`0` 从公开课程列表隐藏 |
| `cover_mode` | TEXT | `default` | `default / image / text` |
| `cover_image` | TEXT | NULL | 管理员上传图片的数据 URL |
| `cover_text` | TEXT | NULL | 管理员设置的 1–6 字文字封面 |

### 内置课程

在 `builtin_course_overrides` 增加同名字段。现有 `hidden` 保持原语义，只表示管理员删除内置课程后写入的墓碑；`visible=0` 表示可恢复的暂时隐藏。两者不得复用。

数据库迁移为已有课程和已有内置覆盖记录补齐安全默认值：`visible=1`、`cover_mode='default'`。

### 封面解析规则

按以下优先级生成当前封面：

1. `cover_mode='image'`：使用 `cover_image`。
2. `cover_mode='text'`：使用 `cover_text`，不显示基础图片。
3. `cover_mode='default'`：上传课程使用当前发布版本的原封面；没有发布版本时使用最新版本。内置课程使用 `BUILTIN_COURSES` 的 `coverUrl` 或 `coverText`。
4. 基础图片和基础文字均不存在时，沿用现有规则显示课程标题首字。

图片模式保存新图片时替换 `cover_image`；文字模式保存时更新 `cover_text`。非当前模式的已有覆盖值可以保留，便于再次切换。选择“原封面”会清除 `cover_image` 和 `cover_text`。

## 可见性语义

- 上传课程只有在 `status='published'`、存在 `current_version_id` 且 `visible=1` 时进入课程广场列表。
- 内置课程在线时应用服务端覆盖；`hidden=1` 或 `visible=0` 的项目不进入课程广场列表。
- 隐藏不修改审核状态、版本指针或包文件。
- 隐藏课程仍出现在管理员列表和所有者的“我的课程”中。
- 可见性是公开列表的展示开关，不是新的下载授权模型；已发布课程的既有访问与本地缓存行为不变。
- 后端离线时无法取得内置覆盖，前端继续显示静态内置课程，这是本地优先回退的既有语义。

## 原始展示与当前展示

编辑弹层顶部使用现有布局机制呈现两个不嵌套卡片的预览区：

- **原始展示**：只读，显示原始标题、副标题、简介、作者以及原始图片或文字封面。
- **当前展示**：只读预览，显示平台字段和展示覆盖合并后的实际效果。

上传课程的原始展示从当前发布版本的 `.pigeon` 读取；没有发布版本时读取最新版本。读取只发生在管理员打开编辑弹层时，不写回课程包。内置课程的原始展示来自前端 `BUILTIN_COURSES`。

打开弹层时，表单按当前保存值初始化：可见性开关反映 `visible`，封面分段控件选中 `cover_mode`，并展示已有 `cover_image` 或 `cover_text`。修改表单时只更新“当前展示”预览，“原始展示”保持不变。取消编辑不修改任何值。

桌面端两个预览区并排，移动端按“原始展示 → 当前展示 → 编辑字段”纵向排列。布局使用 grid、flex 和 gap，不增加基于 top/left 的绝对定位。

## 管理面板交互

- 继续使用现有“编辑课程”弹层，不新增页面。
- 字段标签改为“发布人（平台）”和“作者（内容署名）”。
- 增加“课程可见”开关。
- 增加“原封面 / 图片 / 文字”分段控件。
- 图片模式显示图片预览和文件选择按钮。
- 文字模式显示 1–6 字输入，并使用现有课程文字封面风格实时预览。
- 当前不可见课程在管理列表中显示“已隐藏”状态，但仍可编辑和恢复。
- 所有颜色、字体、边框、按钮和间距沿用现有设计令牌与管理面板组件。
- 保存成功后关闭弹层并刷新课程列表；保存失败时保留输入和预览，并显示现有风格的错误提示。

## 接口设计

### 读取编辑详情

管理端课程详情响应包含：

- 当前课程元数据。
- 原始展示信息；上传课程由服务端从选定版本包中只读解析。
- 打开弹层前已保存的 `visible`、`cover_mode`、`cover_image`、`cover_text`；这些是平台字段，不属于课程包原始展示。
- 用于默认模式预览的基础封面信息。

内置课程的原始展示由前端登记表补齐，服务端返回当前覆盖值。

### 保存编辑

扩展现有 `PATCH /api/admin/courses/:ref`，使其同时接受 JSON 元数据更新和 multipart 表单。multipart 请求可携带图片文件，并包含元数据、`visible`、`coverMode` 和 `coverText`。

服务端完成全部校验后，在一个 SQLite 事务中更新元数据与展示字段，避免部分保存。响应返回最新原始字段和合并后的课程数据。

## 校验与错误处理

- `visible` 必须是明确的布尔值。
- `cover_mode` 只允许 `default / image / text`。
- 图片只允许 PNG、JPEG、WebP，最大 600 KB；服务端同时检查声明 MIME 和文件签名。
- 首次切换到图片模式时必须提供图片；已有 `cover_image` 时允许只切回图片模式。
- 文字模式必须提供去除首尾空白后的 1–6 个 Unicode 字符。
- 默认模式清除两个封面覆盖字段。
- 非法输入返回现有统一错误结构，不修改数据库。
- 审计记录课程编辑、可见性变化和封面模式变化，但不写入图片数据正文。

## 测试与验收

### 数据与接口

- 迁移后既有课程保持可见并使用原封面。
- 上传课程和内置课程都能保存并读回四个展示字段。
- `hidden` 墓碑和 `visible` 开关互不影响。
- 图片、文字、原封面三种模式正确合并；恢复原封面只清除封面覆盖。
- 图片格式、签名、大小和文字长度校验覆盖边界值。
- 任一字段非法时，元数据和展示字段均不发生部分更新。
- 不可见的已发布课程不出现在广场列表，但仍出现在管理员列表和所有者课程列表。
- 审核状态、当前版本、最新版本和课程包文件在编辑前后保持不变。

### 前端

- 弹层正确展示上传课程与内置课程的原始展示。
- 表单按四个展示字段的原值初始化。
- 当前展示随元数据、可见性和封面模式实时更新，原始展示不变。
- 取消、保存成功和保存失败行为符合设计。
- 桌面、移动端、亮色、深色均无文字溢出、布局重叠或不一致样式。
- 后端离线时，内置课程继续按静态默认信息展示。

### 回归命令

- 管理课程 API smoke。
- 现有后端 smoke。
- 课程覆盖单元测试。
- Vite 生产构建。
- Playwright 桌面、移动端、深色和离线检查。
- UTF-8 无 BOM、无 mojibake，以及禁用样式检查。

## 完成标准

管理员可以在同一编辑弹层中对照课程原始展示和当前展示，修改元数据、可见性及封面覆盖；公开课程列表正确应用可见性和封面结果；课程审核、版本和 `.pigeon` 文件完全不变；所有新增行为通过上述自动化与视觉验证。
