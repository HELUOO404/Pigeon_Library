# 2026 职业赛道初赛课程下载与排版计划

## 一、真实网站调研结论

本计划不是根据旧资料推测，而是基于已经登录后的真实网站探测结果。已只读抓取两个代表小节：制造章节 `0-1` 与包含实验 42、43 的封装章节 `4-1`。原始响应保存在 `reports/live-component-probe/`。

网站每个小节固定包含四个栏目：概述、理论知识、讲课视频、作业；其后的实验和工程为同一小节的附加栏目。下载时不能只看第一个栏目，也不能因为栏目没有题目而跳过。

| 网站栏目 | 真实页面机制 | 下载要求 |
| --- | --- | --- |
| 概述 | 直接返回 `div.ax-article`，可能含 `sectiontext`、`sectionimg`、表格和相对图片 | 保存原始 HTML；下载并改写所有相对图片为课程内路径。 |
| 理论知识 | 页面脚本的 `strllzs` 列出知识点，动态生成 `object data="../Html/<知识点>.html"` | 先保存目录页，再逐个请求全部 `Html/*.html` 子页；子页文本、图片、表格必须原样保留。 |
| 讲课视频 | 页面脚本以 `strvideoname` 和 `strvideonum` 定义视频列表，播放器地址为 `PlayVideo.php?videoId=<编号>` | 解析并下载列表中的每一个视频，而非只下载默认第一条；保留标题、顺序、封面和字幕。 |
| 作业 | 直接返回题目表、选项和 `workresult` 已保存答案数组 | 逐字保存题干和选项；答案与解析独立存放，不能改写题目。 |
| 实验、工程 | 可能有多个子栏、普通下拉题、工艺流程题、仿真按钮、canvas、动态视频或 iframe | 每个子栏单独抓取原始 HTML、脚本依赖、媒体和页面声明的动作。无题目的子栏同样抓取。 |

已完成的活动原始快照覆盖 49 个纳入范围的活动、80 个子栏。资源清单已识别 105 个直接资源引用和 54 个含动态视频端点的页面。实验 43 必须以已验证的选项顺序抓取逐步短片，不能简化成普通单视频。

## 三、下载执行顺序

### 阶段 A：保存源网页

1. 按章节、小节、栏目建立稳定键，例如 `chapter-1/section-1/theory/`。
2. 依次请求概述、理论目录、理论子页、讲课视频目录、作业、实验菜单、实验子栏、工程菜单、工程子栏。
3. 每个响应保存原始 UTF-8 HTML，不格式化、不清理空格、不替换错别字。
4. 为每页记录：网站栏目、章节小节、页面标题、抓取时间、原请求参数、字节数、SHA-256 和引用资源列表。

### 阶段 B：下载资源闭包

1. 从原始 HTML、内嵌 CSS 和脚本中提取 `src`、`href`、`poster`、`srcset`、`object data`、iframe、CSS `url()`、视频编号和仿真动作返回的资源。
2. 相同 URL 只下载一次，按内容哈希保存；清单同时保留原 URL 与引用页，防止同名文件覆盖。
3. 讲课视频和仿真视频按真实 `videoId` 下载；下载后检查文件大小、MIME、可解码性和时长。
4. 仿真页面保留页面 HTML、JS、CSS、图片、字体和媒体的完整依赖图，不执行来源未知的第三方脚本。
5. 资源闭包检查必须为零缺失、零外链。未能下载的动态资源不能用占位图或网络 URL 代替。

### 阶段 C：建立三个课程源

| 课程 ID | 显示名称 | 网站章节 |
| --- | --- | --- |
| `2026-ic-manufacturing` | 2026职业赛道初赛IC制造 | 第一章 |
| `2026-ic-devices` | 2026职业赛道初赛IC器件 | 第二、三章 |
| `2026-ic-packaging` | 2026职业赛道初赛IC封装 | 第四、五、六章 |

三个课程源均放入 `courses/2026-vocational-preliminary/`。名称不得包含“课程包”。课程正文、题目和表格以网站源 HTML 为唯一权威；奥施特资料只用于对照图片和排查答案，不覆盖网站原文。

## 四、排版方案

### 参考已有课程包

`courses/ic-packaging` 是主参考：它使用章节/小节/知识点树，并以 `paragraph`、`image`、`numTitle`、`boldCaption`、`paramsTable`、`summaryBox`、`compareBox` 和 `sectionQuiz` 组织内容。`courses/demo-course` 证明了 `sandbox` 可承载真正依赖 JavaScript 的页面。

新课程采用同一阅读节奏：正文连续、标题紧凑、图表贴近解释，避免把每段文字做成卡片。颜色、字体、间距一律沿用 `app/src/styles/tokens.css` 和学习页现有样式，不在课程数据里写展示用空格或自行定义色值。

### 网站内容到课程块的映射

| 网站内容 | 课程块 | 排版原则 |
| --- | --- | --- |
| 简单文字与标题 | `paragraph`、`numTitle`、`boldCaption` | 按网站原句拆块，不改变字符。 |
| 单图、图注 | `image`、`boldCaption` | 图片本地化，保留原顺序和尺寸比例。 |
| 普通参数表、比较表 | `paramsTable`、`compareBox` | 仅在不损失单元格结构时转换。 |
| 合并单元格、复杂图文表、原网页图表 | `html` | 保留原表结构；课程 CSS 只做容器宽度和移动端横向滚动。 |
| 理论子页 | 单独知识点；简单页转结构化块，复杂页保留 `html` | 原目录顺序由 `strllzs` 决定。 |
| 讲课视频 | `video` | 每个 `strvideoname` 对应一个本地视频块。 |
| 作业与实验题目 | `questionBank` + 引用 | 题干、选项、正确答案严格来自当前网站；解析单独增加。 |
| 普通仿真 | `sandbox` | 本地 iframe 与依赖清单，保留原逻辑。 |
| 实验 43 的连续短片 | `stepSimulation` | 左侧题目，右侧不可交互本地短片；每步使用下拉栏；答对播放、结束保留尾帧、再解锁下一步。 |

## 五、验收与交付

1. 忠实度校验：每段正文、题干、选项均可在对应的原始网站快照中找到；失败即停止打包。
2. 资源校验：课程包内无外链、无缺图、无缺视频、无未记录脚本依赖。
3. 视觉校验：桌面和 390px 手机截图检查图片正常、表格不重叠、文字不溢出、仿真下拉栏不拉长面板。
4. 运行校验：本地断网后讲课视频、仿真和实验 43 连续短片均可播放；浏览器网络日志无资源失败。
5. 打包交付：每个课程生成部署 `.pigeon`、同级媒体目录和完整 `.full.pigeon` 备份；生成 SHA-256 清单。

在上述前置门槛全部通过之前，本计划不允许进入批量下载阶段。
